## 验证边界

- 本环境没有可连接的独立 Chrome、Edge 浏览器，因此没有将内置 Chromium 检查声称为两款浏览器分别实测。发布前可在本机 Chrome、Edge 各打开一遍网站。
- 离线验证采用依赖扫描、离线缓存校验及同源 CSP，没有改变用户操作系统的联网状态。日常运行无需外网；官方链接依然需要联网。
- 打印按钮已接入 `window.print()` 并提供专用打印样式；内置浏览器没有展示系统打印预览，纸张分页与实际打印需在 Chrome 或 Edge 的打印预览中复核。
- 当前内容是框架与少量通用示例，尚未完成面经整理或年度招生政策维护。
