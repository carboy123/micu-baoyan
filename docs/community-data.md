## 面经以按院校整理稿为准

`参考资料/按院校整理/` 共 164 条来源记录：M001–M051 为旧稿独立样本，Q2026-001–Q2026-113 为问卷记录。Q2026-001 / 002 的院校仅填数字，继续留在本地待核，其余 162 条公开。旧链接及 `recordId` 不变：M001 对应 `legacy-001`，Q2026-003 对应 `survey-2026-003`。

按照该目录的年份口径，公开面经中 2025 年申请 9 条、2026 年申请 153 条。原稿写法“2025届 / 2026届”保存为 `originalCohort` 和正文，不当作标准毕业届别。来源中的年份冲突、疑似跨来源重复和暂定归类仍保留，不补造信息。未回答题号保留在原稿，页面不展示逐题缺项说明，也不附加统一的回忆与评价段落；投稿者原有的限定语和工作室署名保留。导入器采用相同规则，后续导入不会重新添加这些尾注。

顶部“学员经验”默认进入整体成果；进入面试与申请经验、优秀学员及其详情时，该一级导航仍保持选中。面经详情的返回入口指向面试与申请经验列表并保留筛选状态。

单校或培养单位使用 `school`；多校合填使用 `schools` 数组建立多个筛选入口，但整篇只保存、计数一次。Q2026-011 可由山东大学、苏州大学和长安大学找到，共同回答不拆分成三份经历。院校/培养单位沿用整理稿的独立分类。

## 感言与个人主页分开

感言使用 `type: reflection`、`kind: 上岸感言`、唯一 `recordId`、有效 `periodId` 和本人愿意公开的署名。成果页按 `cohort-2026 / cohort-2027` 展示，详情返回对应届别；不会进入面试与申请经验的数据、筛选或相关推荐。全站搜索仍可找到感言，类别为整体成果。

50 篇 2026 届感言迁移后保留旧地址 aliases。2027 届的 68 篇有效感言从原匿名档案中原样提取，82 份自动生成的个人主页已撤下；不再把去向问卷当成优秀学员展示。没有感言的记录仍保留在成果统计中。

整体成果页按届别纵向展示感言全文，每页 10 条，页码保存在网址的 `rpage` 参数中；刷新和返回可恢复页码，切换届别回到该届第一页。不开启 JavaScript 时完整显示感言，打印时也显示全部正文。旧详情地址继续可访问。统计表不显示人数为 0 的“未提供”空分类，原始统计数据保持独立维护。

后续每位学员仍可自愿投稿个人主页，昵称优先、实名自愿；工作室审核后再展示。面经 `studentId` 仅在确认作者和公开范围后关联；不凭学校、成绩或措辞猜测身份。

## 成果统计保持独立

2026 届对应本科 2022 级、2025 年保研申请；2027 届去向问卷未单列申请年，仍留空。面经的申请年与成果问卷的毕业届别是不同字段，不互相覆盖。

两届当前均使用匿名汇总快照，由 `layouts/_partials/site/outcomes-data.html` 渲染。本科层次和去向层次沿用原问卷选项，不根据学校名称重新分类；分母保持 64 / 82，2027 届已排除一条完全重复提交。感言迁移及主页撤下不改变人数或比例。

新投稿 `countInOutcomes` 默认 `false`。只有维护者确认是新增且获准统计的样本，才设为 `true` 并填写有效 `periodId`；认领已在汇总中的旧样本不能重复计数。现有聚合逻辑仍支持以后另建仅由审核档案汇总的 `profileBased` 分组。

之前核对的 8 条去向简称/笔误更正保持不变；中国地质大学按用户确认暂不区分校区。去向使用最终选择，不从面经 offer 字样生成，不把记录构成解释为全体学员成功率。

## 导入与校验

```powershell
python scripts/import-school-interviews.py --source-dir '参考资料/按院校整理'
python scripts/import-studio-data.py
python scripts/check-contributions.py
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/core.test.cjs tests/students.test.cjs tests/outcomes.test.cjs
python tests/outcome-aggregation.py --hugo tools/hugo/hugo.exe
```

导入器默认只读检查，写入必须显式使用 `--write`；覆盖已有整理内容前核对差异，并按导入器说明使用 `--replace-existing`。不要覆盖学员后来补充的内容。原件不随公开仓库分发，因此 CI 不运行原稿导入，而执行字段、构建和内链检查。

生产构建、子路径验收和 GitHub Pages 发布沿用 README。PR 投稿流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)，自动检查不代替真实性和公开范围的人工审核。
