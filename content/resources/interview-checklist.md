这是编者检查清单，不是学校统一规定的参营要求。先对照本次院系通知删改；它不包含真实学员面经或未公开考题。

## 先把通知读完整

- [ ] 已确认院校、学院、项目、批次和通知适用年度。
- [ ] 已记录考核时间、地点／线上入口及报到要求。
- [ ] 已确认是否需要回复、参加确认或补交材料。
- [ ] 已查清展示形式、允许使用的软件与辅助工具。
- [ ] 已保存正式通知与咨询渠道的离线副本。

## 材料与展示

- [ ] 证件、证明与打印材料按本次要求准备。
- [ ] 展示文件是本次版本，没有误留其他学校或导师名称。
- [ ] 图表的指标、条件和比较对象能够解释。
- [ ] 项目讲解能够区分团队工作与个人贡献。
- [ ] 已测试文件打开、字体显示及必要的离线备份。
- [ ] 已按通知给定的时长练习，并尝试回答中途追问。

## 线上参加

- [ ] 身份展示方式、声音、摄像头和共享方式符合通知要求。
- [ ] 网络、电源与通知要求的软件提前测试。
- [ ] 共享内容中没有无关窗口或个人资料。
- [ ] 已了解突发连接问题时的官方联系办法。

## 线下参加

- [ ] 校区、入口、报到地点和到达时间已经核对。
- [ ] 已按要求携带证件与材料。
- [ ] 交通、住宿、费用和票据要求有明确依据；不默认所有项目报销。

## 英语与项目表达

尝试用简短语言解释学习背景、一个真实项目和未来兴趣。遇到不熟悉的问题，先确认含义，再说明已知部分、推理过程或尚未掌握的边界；不虚构实验与阅读经历。

考核期间遵守保密规定，不公开未公开题目、他人答辩内容和评审信息。考核后先整理自己的知识薄弱点及公开可分享的复盘，再按官方通知跟进下一步。
