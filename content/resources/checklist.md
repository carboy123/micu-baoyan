## 材料准备

- [ ] 已核对申请资格、材料清单和适用年度。
- [ ] 简历中的经历、个人贡献与结果状态准确。
- [ ] 个人陈述按本项目要求准备（如要求）。
- [ ] 成绩、排名证明的学期范围、口径与盖章符合要求。
- [ ] 英语证明符合对应通知要求。
- [ ] 竞赛、项目、科研材料能够对应实际经历。
- [ ] 推荐材料按要求准备和提交（如要求）。
- [ ] 申请表、身份材料及其他文件完整（按通知提供）。

## 提交前

- [ ] 文件命名、格式、大小、签字与盖章已检查。
- [ ] 材料中的个人信息、日期和项目名称一致。
- [ ] 已分别保存原始凭证、可编辑稿与本次提交稿。
- [ ] 已打开最终提交文件，确认内容可读、页码完整。
- [ ] 确认提交渠道、截止事项与联系信息。
- [ ] 已保存提交副本和确认信息。

## 后续跟进

- [ ] 记录待补交材料和需要本人回复或确认的事项。
- [ ] 记录考核方式与所需准备。
- [ ] 将院系阶段结果与正式系统手续分别记录。
