“保研”通常指推荐免试攻读研究生。对推免硕士而言，免试指免全国硕士研究生招生考试的初试，**仍需要通过接收单位规定的考核**。直博按相应博士招生和推免规定办理。

## 本校推荐与目标院校接收

| 环节 | 查哪里 | 做什么 |
| --- | --- | --- |
| 本校推荐 | 本科学校教务部门、学院的办法和当年通知 | 核对条件，申请资格，关注公示和后续手续 |
| 目标院校接收 | 招生院校、学院和培养项目的通知 | 报名、提交材料、参加考核并跟进结果 |
| 正式确认 | 国家推免服务系统与招生单位通知 | 按当年规定处理志愿、复试和待录取等事项 |

本校推荐和目标院校接收需要分别完成，导师意向不能替代其中任何一项。研招网明确，推免资格审核确认、报考、录取与备案等相关工作需要通过国家推免服务系统进行，最终名单以系统备案信息为准。

## 区分申请状态 {#把不同结果分开记录}

“拿到 offer”不是统一的正式状态，应看通知具体写了什么。

| 当前状态 | 仍需关注 |
| --- | --- |
| 预计有本校资格 | 是否进入正式推荐名单并完成相关程序 |
| 已获得本校推荐资格 | 目标院系接收及全国系统手续 |
| 已提交报名 | 是否提交成功、是否通过材料审核 |
| 入营或获邀考核 | 考核结果及后续要求 |
| 优营或考核通过 | 结果效力、名额、双选、再次考核或确认条件 |
| 候补 | 递补规则及回复要求 |
| 导师表达接收意愿 | 院系程序、资格和正式系统状态 |
| 已接受系统待录取通知 | 后续审核、本科学业和入学要求 |

## 夏令营与预推免是什么关系

夏令营可能包含交流、宣讲或选拔；预推免通常指院系在正式录取前组织的预报名、考核等安排。具体环节、参加条件及结果效力以项目通知为准。

“夏令营 → 预推免 → 正式手续”不是每个人必须逐项参加的固定路线。没参加某场夏令营能否申请后续批次，需要查看后续通知。

## 学位类型与培养路径

- **学术学位硕士**侧重学术研究训练；**专业学位硕士**侧重专业实践能力及相应理论训练，两者都要求相应的理论基础与创新能力。
- **直博**是本科后直接进入博士阶段的培养路径。
- **硕博连读**等路径通常涉及进入硕士阶段后的衔接选拔，条件与时间需另行核对。

名称本身不能确定学制、学费、奖助、住宿或分流安排。具体比较方法见 [择校与培养方向]({{< relref "basics/choosing.md" >}})。

## 现在可以开始做的三件事

1. 查本校规则，确认适用条件。
2. 整理已有成绩、英语和项目经历。
3. 根据当前阶段安排课程、实践与申请准备。
