择校要落实到 **学院、专业、研究方向、培养项目和导师安排**。同一学校内，不同项目的申请条件、培养地点和考核方式也可能不同。

## 明确自己的选择依据 {#先写下自己的选择依据}

从喜欢的课程和做过的项目出发，考虑希望获得怎样的理论、工程或研究训练。同时明确自己能接受的培养年限、费用和地点，再比较方向、指导方式与生活环境。

## 分清学位类型与培养路径

| 概念 | 理解重点 | 选择前要查清 |
| --- | --- | --- |
| 学术学位硕士（学硕） | 侧重学术研究训练 | 方向、培养方案、学制、毕业及后续攻博要求 |
| 专业学位硕士（专硕） | 侧重专业实践能力及相应理论训练 | 实践安排、培养地点、学费奖助、住宿与毕业要求 |
| 直接攻读博士（直博） | 本科后直接进入博士培养的路径 | 学位类型、年限、阶段考核、分流及退出安排 |
| 硕博连读等衔接路径 | 进入硕士阶段后依规定申请后续衔接 | 选拔条件、时间、考核与名额 |
| 工程类博士专业学位 | 博士专业学位中的相关培养类型 | 招生对象、申请方式、培养与实践要求 |

学术学位与专业学位同等重要，培养定位有所区别，都要求相应理论基础与创新能力。直博是路径，学术／专业学位是类型，不能把这些概念当成完全互斥的分类。

名称不直接决定学制、收费、住宿、毕业难度或转段安排。考虑直博时，尤其要阅读培养与考核文件，评估自己能接受的研究投入和年限。

## 比较具体项目 {#为每个项目建立比较记录}

| 要了解的内容 | 优先查看 |
| --- | --- |
| 申请资格、考核与双选 | 适用年度的招生办法和通知 |
| 研究方向 | 学院、团队主页及公开成果 |
| 培养地点、实践和联合培养 | 招生简章与培养方案 |
| 学费、奖助和住宿 | 官方收费及支持政策 |
| 阶段考核、毕业与退出安排 | 培养和学位授予文件 |
| 日常指导与合作 | 团队介绍及实际沟通 |

区分官方规定、沟通答复与待确认信息。网页过期或说明不清时，向项目负责渠道核实。

## 了解导师，看匹配与实际沟通

阅读导师或团队公开介绍，了解具体研究问题与自己经历的联系，再有针对性地沟通。

职称、网上标签或匿名评价不能直接说明招生名额、指导质量和录取权限。“强 com”“弱 com”也只是非正式概括；审核、双选及导师接收意向的效力，以当前招生规则为准。

[联系导师的方法]({{< relref "application/mentors.md" >}})

## 安排一个自己能管理的申请组合

结合方向匹配、个人条件、材料工作量和实际接受程度选择项目，不存在仅凭背景就一定稳妥的申请。

考核冲突时，先核对是否允许调整或采用其他参加方式，再比较机会、研究匹配与时间成本。
