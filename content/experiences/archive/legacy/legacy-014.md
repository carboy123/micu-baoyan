## 当时的申请与考核

- **基本信息**：2026届 · 夏令营；本科院校层次：211；结果：获得拟录取 / offer
- **考核概况**：强com；线下；15分钟以内
- **进面门槛（个人观察）**：成绩排名、本科院校层次、英语四六级 / 托福 / 雅思
- **考核模块**：常规综合面试、机试 / 上机、英语面试 / 英文翻译、专业课问答 / 抽题、科研 / 项目 / 竞赛追问、PPT汇报
- **综合面试环节**：英文自我介绍、个人简历追问、导师自由提问、专业基础追问、科研 / 项目追问、未来规划 / 读研动机
- **机试范围**：C / C++ 编程、Python 编程、专业软件操作
- **具体机试内容**：C/C++、python、matlab和硬件题四选一
- **英语形式**：英文自我介绍
- **英语问题 / 翻译内容**：无，只有英语自我介绍
- **专业课范围**：机器学习 / 人工智能
- **专业课提问方式**：抽题作答
- **具体专业课问题**：嵌入式人工智能在生活中的应用
- **科研 / 项目 / 竞赛追问方向**：个人具体贡献、技术路线 / 方法原理
- **PPT 要求**：必须准备，要求明确
- **整体感受**：难度：中等；老师风格：温和鼓励型、项目追问多
- **更看重的因素（个人判断）**：成绩排名、本科院校层次、英语水平、科研经历、竞赛经历、专业基础
- **补充建议**：
  - 夏令营考核主要分为两部分，一是机试，二是面试。
  - 机试分为硬件和软件两个方向，选择其一进行考核。硬件考核听说是和电赛综合测评差不多，主包选的是软件，所以不太了解。软件分为C/MATLAB/Python三选一，C主要是偏传统算法的一些题目比如动态规划等，考核完毕之后听同学说今年C的难度较大，考试时间结束都有很多同学没答完，主包选的是MATLAB，MATLAB主要考察的是矩阵的基本运算、积分微分运算、画图、系统设计以及信号处理的内容，Python是今年新开的，主包也不太了解。
  - 面试大概分为八组，每组20多个人，位次靠后的话就需要漫长的等待了。面试教室内有5位老师，别忘记多带几份简历，时间大概十几分钟，主要流程就是先抽一个开放性的题目，内容与仪科院的研究方向相关，也就是导航、机器人和医疗方向，可以详细了解一下，主包抽到的问题是智能感知与传统感知的区别和联系。
  - 回答完开放性问题之后，就是3min的自我介绍，采用英语+ppt的形式。介绍完后老师会针对你的项目问一些针对性的问题：
  - 1.项目的原理
  - 2.看到我数据处理的结果图，让我解释一下以及问我怎么绘制的
  - 3.对项目精度和数据问了一下
