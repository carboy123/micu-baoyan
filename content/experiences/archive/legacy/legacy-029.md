## 这次申请

- **基本信息**：2026届 · 预推免；本科院校层次：985；结果：获得拟录取 / offer
- **考核概况**：弱com；线下；15-30分钟
- **进面门槛（个人观察）**：成绩排名（6/97）、本科院校层次（985）、英语四六级 / 托福 / 雅思、科研经历、导师提前沟通结果
- **考核模块**：常规综合面试、机试 / 上机、英语面试 / 英文翻译、专业课问答 / 抽题、科研 / 项目 / 竞赛追问、PPT汇报
- **综合面试环节**：中文自我介绍、英文自我介绍、个人简历追问、导师自由提问、科研 / 项目追问、未来规划 / 读研动机、其他（算法题口述解答 算法题一题多解）
- **机试范围**：C / C++ 编程、数据结构与算法
- **具体机试内容**：基本是各大oj平台简单中等的题目 涉及到一些数据结构的具体应用 比如字符串匹配 括号匹配等 以往有机试的时候基本是简单的语法题 涉及到一些基础算法的题目（回溯，dp等） 以及一道较难的数据结构题目
- **英语形式**：英文自我介绍、英文文献翻译
- **英语问题 / 翻译内容**：给出一段专业文献 要求在限定时间内口述出翻译结果
- **专业课范围**：高等数学、线性代数、通信原理、与科研方向相关的问题
- **专业课提问方式**：围绕项目追问专业知识
- **具体专业课问题**：直接问xx专业课的成绩如何 哪门专业课与你的项目最接近 你在项目中运用了哪些专业课知识
- **科研 / 项目 / 竞赛追问方向**：个人具体贡献、技术路线 / 方法原理、实验设计、创新点、项目难点、不足与改进、论文 / 专利细节
- **具体项目 / 竞赛追问**：
  - 在做这个项目的时候 有没有想到项目中的xx内容可以被运用于哪些方面
  - 为什么会使用xx方法解决这个问题 有没有别的方法可以解决
  - 讲述整个项目的解决思路
- **PPT 要求**：必须准备，要求明确
- **整体感受**：难度：中等；老师风格：项目追问多、聊天了解型
- **更看重的因素（个人判断）**：成绩排名、本科院校层次、英语水平、科研经历、专业基础、导师匹配度、综合背景均衡
- **补充建议**：申请预推免的时候 一定要先和导师取得联系 得到导师推荐基本才能有进面的资格 面试选人标准更看重个人的bg和rank排名 rank较低的同学要准备一套rank低 但是能获得保研资格的说法 以及要面对导师追问为什么rank低 rank高的同学要给出充足的不放课题组鸽子的 理由 导师会通过追问你的科研项目来了解你的科研能力和科研思路 一定要对科研项目最好充足准备
