## 当时的申请与考核

- **基本信息**：2026届 · 其他（属于是夏令营和预推免同时开的，夏令营用来报销食宿，预推免用来优营考核）；本科院校层次：双一流；结果：获得拟录取 / offer
- **考核概况**：强com；线下；15-30分钟
- **进面门槛（个人观察）**：成绩排名（1/160）、英语四六级 / 托福 / 雅思、科研经历、项目经历、专业匹配度
- **考核模块**：常规综合面试、英语面试 / 英文翻译、专业课问答 / 抽题、科研 / 项目 / 竞赛追问、其他（不准带PPT的面试）
- **综合面试环节**：中文自我介绍、个人简历追问、导师自由提问、专业基础追问、科研 / 项目追问、其他（英语资料朗读和翻译，英语问题提问和回答）
- **英语形式**：英文日常问答、英文文献翻译
- **英语问题 / 翻译内容**：
  - 1.英语问题：你的这一门课程分数为什么这么高？
  - 回答可以从自身努力+老师的帮助回答
  - 2.翻译问题：首先朗读一下文献，然后翻译，文献内容是可移动支付对现代社会的影响，包括让社会变成了少现金社会，更加方便快捷，但是也给老年人带来了负担
- **专业课范围**：信号与系统、通信原理、单片机 / 嵌入式、机器学习 / 人工智能、与科研方向相关的问题、其他（还有c语言，更多是看你简历上写的个人核心课程分数写了什么课程）
- **专业课提问方式**：围绕项目追问专业知识
- **具体专业课问题**：
  - 面试情况（是结合简历问的专业课）
  - 1.pid的原理（简历）
  - 2.冒泡排序的原理（简历写的课程）
  - 3.你的这门课程为什么分数这么高（英语）
  - 4.采样频率的选择，奈奎斯特定理（带通，低通）
  - 5.不同窗函数的特点，以及窗函数的作用和目的（简历）
- **科研 / 项目 / 竞赛追问方向**：个人具体贡献、技术路线 / 方法原理、实验设计、结果指标、创新点
- **具体项目 / 竞赛追问**：
  - 我的项目是岚哥的信号分离装置，一个单兵作战系统（各种传感器+无线传输数据），一个智能植物管家（做了网站接了api）
  - 1.你对语义通信的了解（简历）
  - 2.你用嘉立创画过哪些板子？（简历）
  - 3.英语翻译——可移动支付对现代社会的一些影响
  - 4.你的web界面开发，开发了一个什么界面（简历）
  - 5.你使用过pytorch搭建信号处理模型，你做了什么项目？（简历）
  - 6.你说你对心率血氧等参数都进行过信号处理，单片机是一起读取的还是分开读取处理的？处理过程中需要注意什么（简历）
  - 7.对我的比赛奖项进行了追问，主要是问你做了什么东西出来，对应实现的效果如何。（多少毫秒实现识别功能？）
- **整体感受**：难度：中等；老师风格：温和鼓励型、项目追问多、聊天了解型
- **更看重的因素（个人判断）**：成绩排名、英语水平、科研经历、竞赛经历、项目能力、表达与临场反应
- **补充建议**：
  - 1.面试的时候一定要自信，说话声音要大，有个诀窍就是一直盯着老师看就行，让别人害羞不要自己害羞
  - 2.如果遇到不会的项目，及时说明自己负责的工作比较少，不然老师会一直追问下去
  - 3.简历上的每一句话真的都会问到，我简历上有一句，web开发接入了api，老师都问我怎么接的api（我一些更加偏信号的内容相比之下都没问）
  - 4.学校面试甚至说不用带简历，不带简历他就看你报名系统的时候填的资料，所以网上填资料的时候，比如个人自述，不要AI随便生成就交了，要把自己的特点体现出来，比如项目经历之类。
