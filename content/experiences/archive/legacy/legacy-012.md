## 当时的申请与考核

- **基本信息**：2025届 · 夏令营；本科院校层次：211；结果：获得拟录取 / offer
- **考核概况**：强com；线下；15分钟以内
- **进面门槛（个人观察）**：本科院校层次（985较多，211其次，江苏的双非院校也可）、科研经历、竞赛奖项、项目经历
- **考核模块**：常规综合面试、机试 / 上机、英语面试 / 英文翻译、专业课问答 / 抽题、科研 / 项目 / 竞赛追问、PPT汇报
- **综合面试环节**：英文自我介绍、个人简历追问、专业基础追问、科研 / 项目追问
- **机试范围**：C / C++ 编程、Python 编程、其他（matlab编程）
- **具体机试内容**：第一题是矩阵运算，第二题是绘制指定函数的曲线，第三题是计算函数的微积分，第四题是字符串操作和文件操作，第五题是一个控制系统，建立传递函数模型，求阶跃响应，bode图
- **英语形式**：英文自我介绍
- **英语问题 / 翻译内容**：5分钟左右，全英文带PPT的自我介绍
- **专业课范围**：自动控制原理、与科研方向相关的问题、其他（导航算法，传感器原理）
- **专业课提问方式**：抽题作答
- **具体专业课问题**：
  - 常见导航系统的原理和作用是什么？
  - 可穿戴设备上用到的传感器有哪些？
- **科研 / 项目 / 竞赛追问方向**：个人具体贡献、技术路线 / 方法原理
- **具体项目 / 竞赛追问**：
  - 有一个大创项目，融合了GPS、IMU等多个传感器，问我用了哪些导航算法，怎么减小定位误差
  - 23年电赛控制二维云台，问摄像头视觉模块循迹的实现方法
- **PPT 要求**：必须准备，要求明确
- **整体感受**：难度：中等；老师风格：温和鼓励型、压力面试型、项目追问多
- **更看重的因素（个人判断）**：本科院校层次、英语水平、科研经历、竞赛经历、项目能力、专业基础、表达与临场反应、综合背景均衡
- **补充建议**：
  - 面试建议：
  - 在专业课题目问答之后，老师一般不会马上去问PPT中的内容，因为各个老师需要时间去翻阅你的资料，并且做笔记记录你有哪些杰出的地方，或者是他感兴趣的地方，因此，这个时候老师一般会问你为什么要报仪科学院，学院里感兴趣的方向是什么？这个时候要注意，一定要答出自己的研究方向，是和仪科学院的几大方向是重合的，是在这几方面有基础的，想要继续进行深造。
  - 接下来，老师一般就会对你的个人简历或者PPT进行提问了，大部分都会先问科研部分。如果你有论文或专利的话，老师一般会让你解释整个论文的过程或专利的过程。那么其中涉及到的一些重点算法也是老师主要考察的内容。
  - 提问科研内容之后，也会抓着竞赛的细节进行提问，例如某个电路是怎么设计的，它具体的作用是什么？这些较为原理性的问题是老师考察的重点，也是拉开差距的地方，因此在准备的过程中一定要细致。
  - 在面试的过程中，千万不要老师问你什么，回答什么，不要让老师的问题变成一般疑问句。要在老师的问题基础上为老师进行深入的解答和讲解。最好是把老师讲的听蒙了。
