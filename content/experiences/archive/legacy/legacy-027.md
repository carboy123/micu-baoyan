## 当时的申请与考核

- **基本信息**：2026届 · 预推免；本科院校层次：双非；结果：获得拟录取 / offer
- **考核概况**：强com；线下；15-30分钟
- **进面门槛（个人观察）**：成绩排名（2/106）、英语四六级 / 托福 / 雅思、科研经历、竞赛奖项
- **考核模块**：常规综合面试、英语面试 / 英文翻译、专业课问答 / 抽题、科研 / 项目 / 竞赛追问
- **综合面试环节**：中文自我介绍、英文自我介绍、个人简历追问、导师自由提问、专业基础追问、科研 / 项目追问、未来规划 / 读研动机
- **英语形式**：英文自我介绍、英文文献翻译
- **英语问题 / 翻译内容**：
  - 1.用英文说明为什么想来南开
  - 2.用英文描述一下你的第二个项目经历（最让我觉得懵逼的，但我之前也准备了）
- **专业课范围**：模拟电子技术、数字电子技术、与科研方向相关的问题
- **专业课提问方式**：随机自由提问
- **具体专业课问题**：
  - 1.什么是pn结
  - 2.有哪些时序逻辑电路
- **科研 / 项目 / 竞赛追问方向**：个人具体贡献、技术路线 / 方法原理
- **具体项目 / 竞赛追问**：1.你在这个项目中主要是做了哪些工作
- **整体感受**：难度：中等；老师风格：温和鼓励型
- **更看重的因素（个人判断）**：成绩排名、本科院校层次、英语水平、表达与临场反应
- **补充建议**：南开之前都是弱com学校因为有开夏令营但在2026届取消夏令营，变为强com，由学院统一面试，一共有5位老师，但都很温和，第一轮初筛很卡本科院校，但由于还是传统弱com学校转型，联系的导师发力了，最后入面拿下，一般建议拿其他学校当保底来冲要不然会很难受
