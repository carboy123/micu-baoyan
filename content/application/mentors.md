联系导师用于了解研究内容、匹配程度和后续安排。是否需要提前联系、何时双选、导师在选拔中承担什么职责，取决于具体院系规则；积极回复不能替代正式招生结果。

## 联系前先完成四件事

1. 找到导师或团队的官方页面，核对姓名、单位和公开联系方式。
2. 阅读近期方向介绍或公开成果，分清长期研究领域与本轮招生安排。
3. 准备自己能独立解释的课程、项目或研究经历。
4. 写清本次想了解的一两个问题，避免只发送泛泛的“希望加入”。

阅读论文时，把已经理解的研究问题、仍不理解的技术环节、与自己经历的真实联系分开记录。无需假装完全读懂，也不要把未经核实的理解写成确定结论。

## 初次邮件怎样组织

主题应能看出申请用途。正文简要说明申请身份、相关经历、研究兴趣和本次请求，附必要且易读的材料。发送前逐项检查老师姓名、学校、邮箱、附件与申请年份。

下面是工作室基础稿中的空白写作框架，方括号均需按实际情况替换：

```text
主题：[入学年度及申请类型] 研究方向交流申请 — [姓名 / 本科单位]

[老师称谓]：

您好。我是[真实在读身份]，计划申请[具体年度及类型]。
阅读您团队公开的[具体研究或方向介绍]后，我希望了解[明确问题]。

我在[课程 / 项目 / 科研]中负责[本人工作]，目前形成了[真实结果或认识]。
这段经历使我对[具体问题]产生兴趣，希望进一步了解贵团队相关工作。

想请教[当前招生方向 / 正式申请渠道 / 是否方便进一步交流]。
附件为[实际附上的材料]。感谢您阅读。

[姓名]
[日期及必要联系信息]
```

只写实际阅读过、做过且能够解释的内容。针对不同对象调整问题，不把老师姓名替换后就当作已经完成研究匹配。

## 按当前状态提出问题

| 当前状态 | 可以进一步确认的事项 |
| --- | --- |
| 尚未报名 | 是否有相关招生方向，正式申请渠道在哪里 |
| 已提交申请 | 如要求补充材料，具体交什么、交给谁 |
| 已获邀考核 | 是否另有团队交流，与院系考核如何衔接 |
| 已取得阶段结果 | 是否仍有双选或审核条件，下一步由谁通知 |
| 收到口头积极反馈 | 反馈在当前招生流程中意味着什么 |
| 自己的申请安排改变 | 应向谁说明，如何及时准确地更新状态 |

这张表是准备问题的建议，不是各院系通用流程。不要仅凭交流措辞自行判定“已经录取”或“无需后续操作”。

## 记录回复与后续动作

为每次联系记录发送时间、回复要点、需补材料、是否安排交流，以及下一次行动的触发条件。没有回复，只能说明尚未收到回复，不自动等于拒绝或默认同意。

需要跟进时，先看对方是否已给出处理时间、官方通知是否已经更新，再围绕新进展或待确认事项简洁说明。若决定不再继续某项目，按相应流程及时沟通，避免让对方依据已失效的信息安排后续工作。

## 将沟通结果放回正式流程中理解

导师交流、本科院校推荐资格、院系考核和全国系统状态应分别记录。只有按各环节的正式要求完成相应手续，才能准确判断自己的申请状态。
