# 米醋保研指南 · 联系导师邮件框架

版本：2026-09-27。这是编者空白模板，不是学校规定或统一招生表格。先按目标项目的实际要求删改；没有依据的字段可以留空，不为了填表补造信息。

## 写之前

先从导师或团队的官方页面核对姓名、单位、公开联系方式和研究方向，再确定本次想了解的问题。是否需要提前联系以及联系在选拔中的作用，要看院系实际规则。

## 空白邮件

```text
主题：[入学年度及申请类型] 研究方向交流申请 — [姓名／本科单位]

[老师称谓]：

您好。我是[真实在读身份]，计划申请[具体年度及类型]。
在阅读您团队公开的[具体研究或方向介绍]后，我希望了解[明确问题]。

我在[相关课程／项目／科研]中负责[本人工作]，目前形成了[真实结果或认识]。
这段经历使我对[具体问题]产生兴趣，也希望进一步了解贵团队的相关工作。

想请教[当前招生方向／正式申请渠道／是否方便进一步交流]。
附件为[实际附上的材料]。感谢您阅读。

[姓名]
[日期及必要联系信息]
```

方括号均为填写提示，发送前应全部替换或删除。没有读过的论文、没有参与的工作，不写成已有经历；不要保留占位符后群发。

## 发送前检查

- [ ] 老师姓名、单位、称谓与邮箱已经核对。
- [ ] 正文中的研究兴趣能够结合真实经历说明。
- [ ] 本次问题具体，并与当前申请阶段相符。
- [ ] 附件名称、版本及内容与正文相符。
- [ ] 未夹带其他学校或收件人的信息。
