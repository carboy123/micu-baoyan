# 米醋保研指南 · 单个项目的讲解卡

版本：2026-09-27。这是编者空白模板，不是学校规定或统一招生表格。先按目标项目的实际要求删改；没有依据的字段可以留空，不为了填表补造信息。

## 填写原则

每张卡片只写一个自己能够解释的项目。先区分团队整体目标与个人负责范围，再记录方法和结果；没有数字证据时不要编造性能提升。

## 空白讲解卡

```text
项目名称与时间：

```

## 用于讲解时自问

1. 问题为什么这样界定，采用的方法依赖什么前提？
2. 还有哪些可选方案，当时为什么做出这个选择？
3. 哪些是团队成果，哪些由自己独立完成？
4. 比较对象与指标是否合理，结果能说明到什么程度？
5. 哪次失败改变了后续做法，还需要怎样验证？

练习时允许别人中途追问，检查自己能否脱离逐字背诵说明过程。展示时长、页数和格式按实际考核要求调整，不把卡片当成统一面试评分表。
